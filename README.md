# 반경 상가 지도

주소를 검색하거나 지도를 클릭하면, 그 지점 **반경 안의 가게**를 [공공데이터포털 상가(상권)정보 API](https://www.data.go.kr/data/15012005/openapi.do)에서 불러와 지도에 점으로 찍고, **업종별 개수**를 옆에 보여 주는 웹입니다.

- 지도: [Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/) 타일이라 **지도용 키가 필요 없습니다**.
- 주소 검색: OpenStreetMap [Nominatim](https://nominatim.org/)을 써서 **역시 키가 필요 없습니다**.
- 공공데이터포털 **인증키는 로컬 서버에서만** 씁니다. 브라우저에서 도는 코드에는 키가 없습니다.

## 실행하기

먼저 공공데이터포털에서 [소상공인시장진흥공단_상가(상권)정보](https://www.data.go.kr/data/15012005/openapi.do)에 **활용신청**을 하고, 마이페이지에서 **일반 인증키**를 복사해 둡니다. Encoding 키와 Decoding 키 중 어느 쪽이든 됩니다.
(발급 직후에는 키가 활성화될 때까지 1~2시간 걸릴 수 있습니다.)

### Windows — 명령어 없이 켜기

1. [nodejs.org](https://nodejs.org)에서 **LTS** 버전을 설치합니다 (처음 한 번만).
2. [프로젝트 전체 ZIP](https://github.com/lifemomo0054-cmd/lifemomo/archive/HEAD.zip)을 받아서 압축을 풉니다(오른쪽 클릭 → **모두 압축 풀기**).
   `start-windows.bat` 파일 하나만 받으면 동작하지 않습니다. 같은 폴더에 `server.js`와 `public` 폴더가 있어야 합니다.
3. 압축을 푼 폴더 안의 **`start-windows.bat`** 을 더블클릭합니다.
4. 처음 한 번은 까만 창에서 인증키를 물어봅니다. 붙여 넣고(오른쪽 클릭) Enter를 누르면 `.env`에 저장되고, 브라우저가 알아서 열립니다.

끌 때는 까만 창을 닫으면 됩니다. 다음부터는 3번만 하면 됩니다.

### 터미널로 켜기 (Windows / macOS / Linux)

필요한 것: **Node.js 20.12 이상** (따로 설치할 npm 패키지는 없습니다)

```bash
npm start
```
- `.env`에 인증키가 없으면 처음 한 번 터미널에서 물어보고 `.env`에 저장합니다.
  직접 넣고 싶으면 `.env.example`을 `.env`로 복사한 뒤 `DATA_GO_KR_SERVICE_KEY=` 뒤에 키를 붙여 넣으세요.
- 브라우저에서 <http://127.0.0.1:3000> 을 엽니다. `node server.js --open`으로 켜면 브라우저가 자동으로 열립니다.

## 쓰는 법

- **주소 검색**: 도로명·지번 주소나 역·건물 이름을 넣고 검색합니다. 후보가 여러 개면 목록에서 고를 수 있습니다.
- **지도 클릭**: 누른 지점을 중심으로 바로 조회합니다. 주소 검색이 잘 안 되면 지도를 움직여서 원하는 곳을 누르세요.
- **반경**: 100m ~ 2km (상가정보 API의 최대 반경이 2km입니다). 바꾸면 같은 지점으로 다시 조회합니다.
- **업종별 개수**: 대분류 / 중분류 / 소분류로 바꿔 볼 수 있습니다. 업종을 누르면 지도에 그 업종만 진하게 표시하고, 다시 누르거나 **전체 보기**를 누르면 돌아갑니다.
- **가게 정보**: 점에 마우스를 올리면 이름이, 누르면 주소·업종·층이 나옵니다. 한 건물에 가게가 여러 개면 함께 보여 줍니다.
- 지도 점 색은 가장 흔한 **음식·소매·수리·개인** 세 가지만 구분하고, 나머지 업종은 회색입니다. 색이 열 가지나 되면 서로 구분하기 어렵기 때문입니다. 다른 업종은 목록에서 눌러서 따로 보세요.

## 구조

```
브라우저 (public/)                로컬 서버 (server.js)                외부
─────────────────                ─────────────────────               ─────────────────────────────
지도 클릭·주소 검색  ──/api/stores──▶  인증키를 붙여 호출  ──────────▶  apis.data.go.kr (상가정보 API)
                    ──/api/geocode─▶  초당 1회로 제한해 호출 ────────▶  nominatim.openstreetmap.org
지도 타일  ─────────────────────────────────────────────────────────▶  tile.openstreetmap.org
```

| 파일 | 하는 일 |
|---|---|
| `server.js` | 화면 파일을 내려주고, `/api/stores`·`/api/geocode`로 외부 API를 대신 호출합니다. 의존성 없는 Node 내장 모듈만 씁니다. |
| `public/index.html`, `app.js`, `style.css` | 지도·검색·업종별 집계 화면 |
| `start-windows.bat` | Windows에서 더블클릭으로 서버를 켜고 브라우저를 엽니다. |
| `test/server.test.js` | 가짜 상가정보 API를 띄워 서버 동작을 검사합니다 (`npm test`). |

### 인증키를 어떻게 지키나

- 키는 `.env`(git에 올라가지 않음)에서 **서버만** 읽습니다. 브라우저로 가는 응답과 서버 로그에는 키를 넣지 않습니다.
- 서버는 아무 주소나 대신 불러 주는 프록시가 아니라, **반경 조회 한 가지**만 정해진 값으로 호출합니다.
- 기본적으로 `127.0.0.1`에서만 받기 때문에 **이 컴퓨터에서만** 접속할 수 있습니다. 다른 사람이 내 키의 호출 한도를 쓰지 못하게 하기 위해서입니다.

## 설정 (`.env`)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `DATA_GO_KR_SERVICE_KEY` | (필수) | 공공데이터포털 일반 인증키 |
| `PORT` | `3000` | 서버 포트 |
| `MAX_PAGES` | `10` | 한 번 조회할 때 불러올 최대 페이지 수. 1페이지 = 1,000개 = API 호출 1회 |
| `HOST` | `127.0.0.1` | `0.0.0.0`으로 바꾸면 같은 네트워크의 다른 기기에서도 접속할 수 있습니다(대신 그 사람들도 내 키의 호출 한도를 씁니다). |

## 알아 둘 점

- **많이 몰린 곳**: 상가정보 API는 한 번에 1,000개씩 주므로, 가게가 많으면 여러 번 나눠 부릅니다. `MAX_PAGES`(기본 10 → 10,000개)를 넘으면 앞부분만 불러오고 화면에 그 사실을 알려 줍니다. 이때 업종별 개수도 불러온 가게 기준이니, 정확한 개수가 필요하면 반경을 줄이세요.
- **호출 한도**: 공공데이터포털 개발계정에는 하루 호출 한도가 있습니다. 같은 지점·반경은 서버가 10분 동안 기억해 두었다가 다시 부르지 않습니다.
- **데이터 기준 시점**: 상가정보는 분기마다 갱신됩니다. 화면에 나오는 “○○○○년 ○월 기준”이 그 데이터의 기준 월입니다.
- **주소 검색**: Nominatim은 OpenStreetMap 데이터를 쓰기 때문에 상세한 한국 주소는 못 찾을 때가 있습니다. 이럴 땐 동네·역 이름으로 찾은 다음 지도를 누르세요. [이용 정책](https://operations.osmfoundation.org/policies/nominatim/)에 따라 서버가 초당 1회 이하로만 요청합니다.
- **지도 타일**: OpenStreetMap 공개 타일은 개인·가벼운 용도로 쓰는 것이 [이용 정책](https://operations.osmfoundation.org/policies/tiles/)입니다. 여러 사람이 쓰는 서비스로 키우려면 다른 타일 제공자로 바꾸세요 (`public/app.js`의 `L.tileLayer` 주소).

## 자주 보는 오류

| 화면 메시지 | 원인 |
|---|---|
| 서버에 인증키가 없습니다 | `.env`가 없거나 `DATA_GO_KR_SERVICE_KEY`가 비었습니다. 서버를 다시 켜면 키를 물어봅니다. |
| 등록되지 않은 인증키입니다 | 키를 잘못 붙여 넣었거나, 발급 후 아직 활성화되지 않았습니다. |
| 이 인증키로는 상가(상권)정보 API를 쓸 수 없습니다 | 이 API에 대한 활용신청이 승인되지 않았습니다. |
| 오늘 쓸 수 있는 API 호출 횟수를 모두 썼습니다 | 하루 호출 한도를 넘었습니다. `MAX_PAGES`를 줄이거나 내일 다시 쓰세요. |
| 지도 프로그램(까만 창)이 꺼져 있어요 | 서버 창을 닫았습니다. `start-windows.bat`(또는 `npm start`)으로 다시 켜고 새로고침하세요. |
