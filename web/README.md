# LOCAL POPULATION LAB

지역 생활인구 분석 웹서비스입니다. 지금은 **경상북도 김천시 3시간 이상 체류 생활인구 합성데이터**를 다룹니다.

> [!WARNING]
> 화면의 모든 수치는 **합성데이터**에서 계산했습니다. 공식통계가 아니며 김천시의 실제 체류인구를 나타내지 않습니다.
> 화면 상단 배지와 하단 문구, 사이드바에 이 사실을 항상 표시합니다.

## 실행

Node.js **20.19 이상 또는 22.12 이상**이 필요합니다. (테스트 도구 vitest는 22.12 이상)

```bash
cd web
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 `dist/`에 정적 파일 생성 (어느 경로에 올려도 동작) |
| `npm run preview` | 빌드 결과 미리 보기 |
| `npm run typecheck` | 타입 검사만 |
| `npm test` | 집계 엔진을 Python 집계표와 대조 |

## 화면

| 메뉴 | 상태 |
|---|---|
| 01 Overview | **완성** — 핵심 지표, 일별 추이, 월·요일별 일평균, 성별·생애단계 구성, 유입지역 상위 10, 권역별 구성 |
| 02 시간 분석 · 03 연령·성별 · 04 유입지역 | 준비 중 |
| 05 생활인구 지도 · 06 지역 비교 | 준비 중 (지도는 시군구 경계 데이터 필요) |
| 07 데이터 탐색 | 준비 중 |
| 08 AI Insight | 자리만 있음 — **AI 기능은 연결하지 않음** |

- 데스크톱 우선. 1200px 미만(태블릿)은 사이드바가 번호만 보이는 레일로, 768px 미만(모바일)은 서랍 메뉴와 접히는 필터로 바뀝니다.
- 밝은/어두운 화면을 지원합니다(처음에는 OS 설정을 따르고, 상단 버튼으로 바꿀 수 있음).
- 모든 그래프는 **표 보기**로 같은 값을 볼 수 있고, 마우스·키보드로 값을 확인할 수 있습니다.

## 필터

상단 FilterBar의 조건은 모든 화면에 함께 걸립니다. 바꾸면 모든 KPI·그래프가 같은 조건으로 다시 계산됩니다.

| 필터 | 선택 |
|---|---|
| 기간 | 전체 · 분기 · 월 프리셋, 직접 지정. 5월은 데이터가 없어 막혀 있음 |
| 성별 | 전체 · 남성 · 여성 |
| 연령 | 원본 16개 연령대를 생애단계(아동청소년·청년·중장년·고령)로 묶어 여러 개 선택 |
| 거주지역 | 전체 · 외부 유입만(김천시 제외) · 김천시 자체 · 김천 기준 권역 · 시도 · 시군구 검색 |

## 데이터

- 브라우저는 `public/data/population.json` 하나만 읽습니다(약 1.1MB, gzip 약 170KB).
  원본 80,193행을 그대로 담되, 날짜·거주지·성별·연령대를 번호로 바꾸고 체류인구수는 ×100 정수로 적었습니다.
- 이 파일은 저장소 루트에서 `python scripts/build_web_data.py`로 다시 만듭니다([data/README.md](../data/README.md) 참고).
  `python scripts/validate.py`가 이 파일의 모든 행을 전처리 결과와 대조합니다.
- 필터를 바꿀 때마다 브라우저에서 8만 행을 한 번 훑어 다시 집계합니다(`src/data/engine.ts`).
  미리 만든 집계표를 쓰지 않는 이유는 기간·성별·연령·거주지 조합이 무엇이든 모든 숫자가 서로 맞아야 하기 때문입니다.

## 계산 규칙

| 지표 | 정의 |
|---|---|
| 누적 체류인구 | 조건에 맞는 행의 체류인구수 합계. 날짜별 값을 더한 **연인원**이라 실제 인원이 아님 |
| 일평균 체류인구 | 누적 ÷ 선택 기간 중 **데이터가 있는 날 수** (5월처럼 비어 있는 날은 빼고 나눔) |
| 외부 유입 비중 | 거주지가 김천시가 아닌 행의 합계 ÷ 누적 |
| 최대 유입지역 | 김천시 자체를 뺀 거주지 중 합계 1위 |
| 주말 ÷ 평일 | 주말 일평균 ÷ 평일 일평균 (각각 데이터 있는 날 기준) |
| 7일 이동평균 | 그날을 포함한 최근 7일(달력 기준) 중 데이터 있는 날의 평균 |

- 데이터가 없는 날은 0으로 채우거나 보간하지 않고 "데이터 없음"으로 비워 둡니다.
- 김천시 자체(거주지 = 체류지) 행과 상한값(5,932.84) 행은 합계에 포함하되, 화면 아래 메모에 비중을 함께 적습니다.

## 디자인

- 글꼴: Pretendard(본문·숫자), IBM Plex Mono(영문 라벨·번호). 모두 npm 패키지로 함께 빌드되어 외부 CDN이 필요 없습니다.
- 차트 색: 일변량은 파랑 하나 + 회색(강조 형식), 성별은 파랑·주황, 생애단계는 파랑 단일 색상의 명도 단계.
  라이트·다크 각각의 바탕색에 대해 색각 이상 구분도·대비를 검증한 값입니다(`src/styles/tokens.css` 상단 주석).

## 구조

```
src/
├── data/          데이터 읽기·필터·집계 (React와 무관한 순수 함수) + 테스트
├── state/         데이터 로딩, 전역 필터, 테마
├── components/
│   ├── layout/    AppShell · Sidebar · TopBar
│   ├── filters/   FilterBar와 네 가지 필터
│   ├── charts/    추이·막대·가로 막대·누적 막대 (SVG/HTML 직접 구현)
│   └── ui/        패널(표 보기 포함) · 지표 타일 · 아이콘
├── pages/         Overview · 준비 중 화면
└── styles/        토큰 · 레이아웃 · 필터 · 차트 · 페이지
```
